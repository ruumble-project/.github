# Ruumble

**Your [Mumble](https://www.mumble.info/) server as an office building.**
Channels become floors and rooms. You see who sits where and who is talking, you change rooms with a click, and every room has a board for notes, code, images and files. Voice stays in Mumble.

![Ruumble: moving between rooms, a new post on the board](https://raw.githubusercontent.com/ruumble-project/ruumble-server/main/docs/images/ruumble-demo.gif)

## Repositories

| | |
|---|---|
| [**ruumble-server**](https://github.com/ruumble-project/ruumble-server) | The service (one Docker container), the web UI and the Mumble plugin. Start here if you run a Mumble server. |
| [**ruumble-client**](https://github.com/ruumble-project/ruumble-client) | Ruumble Client: a Mumble 1.6 client for Linux with Ruumble built in. One window, no plugin and no browser tab. |

## Get started

- **Server operators:** getting started in the [ruumble-server README](https://github.com/ruumble-project/ruumble-server#get-started).
- **Users on Linux:** download the AppImage, .deb, .rpm or Arch package from the [latest client release](https://github.com/ruumble-project/ruumble-client/releases/latest).
- **What's new:** the [release notes for users](https://github.com/ruumble-project/ruumble-server/blob/main/docs/whats-new/README.md), in plain words and with pictures, newest version on top.
- **Contributors:** see [CONTRIBUTING](https://github.com/ruumble-project/ruumble-client/blob/main/CONTRIBUTING.md). Issues and ideas are welcome in both repositories.
